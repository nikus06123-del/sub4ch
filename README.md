# sub4ch

Автоматически обновляемая подписка живых VPN-конфигов (vless / vmess / trojan / ss / hysteria2 / tuic).

## Подключить в Throne

«Подписки» → «Новая» → вставить URL:

```
https://raw.githubusercontent.com/nikus06123-del/sub4ch/main/sub.txt
```

Зеркало (если raw недоступен провайдеру):

```
https://cdn.jsdelivr.net/gh/nikus06123-del/sub4ch@main/sub.txt
```

Файлы обновляются автоматически программой на компьютере владельца.
В репозитории только подписка: `sub.txt` (base64), `sub_plain.txt` (открытый текст), `stats.json` (статистика).
